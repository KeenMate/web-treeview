Multi-Drag (Select Multiple & Drag as Group)

            
Set selection-mode="multi" and the tree honors OS-explorer drag semantics: Ctrl/Shift-click several rows, then drag any one of them — the whole highlight set moves together. Grabbing a row that's not in the highlight set replaces the highlight with just that row, matching how Finder / Explorer behave.


            

                
Try it

                
    
                    
  1. Ctrl+click on three rows (e.g. Apple, Cherry, Eggplant) — you'll see them highlight.
    2. 
                    
  2. Drag any highlighted row and drop it onto another row.
    3. 
                    
  3. The whole set lands as a group: first node lands at the requested position, the rest chain after it as siblings.
    4. 
                    
  4. Shift+click selects a visual range between two rows.
    5.

Restricted Drop Positions

            
Control which drop positions are valid per node using allowedDropPositionsMember (data-driven, shown below) or getAllowedDropPositionsCallback (runtime per-node logic). Both let the lib snap an attempted drop to the nearest allowed position. Try dragging items to different targets:


            

                
Node Types

                
    
                    
  • 🗑️ Trash - Only accepts child drops (drop INTO, not above/below)
    • 
                    
  • 📂 Projects - All positions allowed (default behavior)
    • 
                    
  • 📄 Files - Only before and after (can't drop INTO a file)
