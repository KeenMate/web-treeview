Logging & Debugging

Explore the categorized logging system with runtime controls

Note: Open your browser's Developer Console (F12) to see the log messages. By default, all logging is disabled in production.

Example 1: Basic Logging Control

Enable and disable logging at runtime. Watch the console as you interact with the treeview (expand, collapse, select nodes).

Example 2: Category-Specific Logging

Enable logging for specific categories. Try expanding nodes with INIT logs, or drag nodes with DRAG logs enabled.

Example 3: Performance Logging

Enable performance logging to measure render times. Load a large dataset to see timing info in the console.

Example 4: Debug Information Overlay

Toggle the debug information overlay on the tree to see internal state.

Available Log Categories

  • INIT - Component initialization, configuration parsing, destruction
  • DATA - Data insertion, tree building, node updates
  • UI - DOM rendering, node reconciliation, context menu
  • DRAG - Drag start/over/leave/drop, cross-tree detection, touch drag
  • RENDER - Progressive rendering batches, render coordinator timing

Usage in Your Code

// Import logging utilities
import {
    enableLogging, disableLogging,
    setLogLevel, setCategoryLevel, LOGGING_CATEGORIES
} from '@keenmate/web-treeview';

// Import performance logging utilities
import {
    enablePerfLogging, disablePerfLogging, setPerfThreshold
} from '@keenmate/web-treeview';

// Enable all logging at debug level
enableLogging();

// Set specific log level for all categories
setLogLevel('info');  // 'trace' | 'debug' | 'info' | 'warn' | 'error' | 'silent'

// Enable specific categories
disableLogging();
setCategoryLevel('UI', 'debug');
setCategoryLevel('DRAG', 'debug');

// Performance logging
enablePerfLogging();
setPerfThreshold(5);  // Only log operations taking > 5ms

// List all categories
console.log(LOGGING_CATEGORIES);

// Disable everything
disableLogging();
disablePerfLogging();
