Custom Templates

Customize node rendering, context menus, loading, and empty states with callbacks

Example 1: Custom Node Template

Use renderNodeCallback to render custom HTML for each tree node. This example shows file icons and sizes.

element.renderNodeCallback = (node, container) => {
    const ext = getExtension(node.data.name);
    container.innerHTML = `
        <div class="custom-node">
            <span class="file-icon">${getIcon(ext)}</span>
            <span class="name">${node.data.name}</span>
            <span class="file-size">${node.data.size}</span>
        </div>
    `;
};

Example 6: FontAwesome Icons

Use FontAwesome classes for toggle and leaf icons. Inject FA stylesheet into Shadow DOM via customStylesCallback.

Rotate mode (chevron)

Swap mode (plus/minus)

Swap mode (folder/file)

No leaf icon (empty space)

// Inject FontAwesome into Shadow DOM via customStylesCallback
tree.customStylesCallback = () =>
    `@import url('https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.7.2/css/all.min.css');`;

// Rotate mode — single chevron rotates 90°
<web-treeview
    expand-icon-class="fa-solid fa-chevron-right"
    leaf-icon-class="fa-regular fa-file">

// Swap mode — two different icons
<web-treeview
    toggle-icon-mode="swap"
    expand-icon-class="fa-regular fa-folder"
    collapse-icon-class="fa-regular fa-folder-open"
    leaf-icon-class="fa-regular fa-file-lines">
